# KeySentry — AI-Powered Frontend Secret Scanner

**KeySentry** is a professional-grade cybersecurity tool designed to scan public website URLs for leaked API keys, credentials, tokens, and insecure code patterns (AI-generated code smells) in client-side HTML, JavaScript, and source maps.

## 🚀 Key Features

- **Deep Secret Discovery:** 50+ regex patterns for AWS, Google, Stripe, OpenAI, Slack, GitHub, and more.
- **AI-Generated Code Smell Detection:** Identifies insecure placeholders and risky boilerplate commonly generated by LLMs.
- **Source Map Analysis:** Automatically follows source map references to find hidden secrets in original source code.
- **Information Leak Audit:** Detects internal IP addresses, admin routes, and verbose console logs.
- **Professional Risk Scoring:** Intelligent security health score (0-100) based on severity distributions.
- **Detailed PDF Reports:** Automated remediation suggestions for every finding.
- **Modern Dashboard:** High-performance Vite React UI with premium dark aesthetics and glassmorphism.

## 🛠 Tech Stack

- **Frontend:** React (Vite), Tailwind CSS, Framer Motion, Lucide Icons, Recharts, Axios.
- **Backend:** Python FastAPI, SQLModel (SQLAlchemy), Aiohttp (Async fetching).
- **Scanner Engine:** Custom Regex-based detection system with contextual risk scoring.
- **Database:** SQLite (Demo mode).

## 📦 Installation & Setup

### 1. Backend Setup
```bash
cd backend
python -m venv venv
# On Windows use: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
The UI will be available at `http://localhost:5173`.

## 🧪 How It Works

1. **Discovery:** Fetches target URL HTML.
2. **Resource Extraction:** Identifies all inline scripts and external JS assets.
3. **Deep Scan:** Each resource is scanned through multiple modules:
   - `api_key_detector`: Finds credentials.
   - `info_leak_detector`: Finds internal metadata.
   - `ai_code_smell_detector`: Finds copy-pasted LLM insecure patterns.
4. **Scoring:** The `RiskScorer` deducts points based on finding severity (Critical, High, Medium, Low).
5. **Reporting:** Results are stored in the local SQLite database and served via REST API.

## ⚠️ Ethical Usage & Disclaimer

This software is for **educational and authorized professional security testing purposes only**. Scanning websites without explicit prior consent from the owner is illegal in many jurisdictions. Always follow ethical disclosure guidelines.
